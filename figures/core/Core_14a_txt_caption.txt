Figure 14a. Opx-perspective pairing matrix (13 rows; LEPR two-pyroxene corpus). Each row compares an opx-trained Method A (y-axis) against a Method B (x-axis) baseline as three panels: (col 1) pressure 1:1 scatter in kbar, (col 2) temperature 1:1 scatter in Celsius, (col 3) disequilibrium map plotting DeltaP = A_P - B_P against DeltaT = A_T - B_T. Rows are grouped into three sections demarcated by header strips: (1) opx ML vs baseline regression models (rows C, G, H, O), (2) opx ML vs our own machine learning models (rows A, F, I; cross-mineral A and I are duplicated on Core_14b), and (3) opx ML vs external machine learning models (rows B, D, E, M, N, P). Each row uses a distinct Okabe-Ito color; identity line is dashed gray; legend gives the per-panel n of valid pairs. The disequilibrium panel overlays a shaded +/- 2 sigma_conformal box (sigma_P = 10.0 kbar, sigma_T = 92.6 C from nb07 conformal calibration); panel title annotates the fraction of residuals inside the box. RMSE of disagreement with 95% bootstrap confidence intervals (n_boot = 500, seed = 42) is shown in each panel title. Row C revives the Putirka 2008 opx-liq 28a/29a comparison: 28a T is real, but 29a P is not computed in the corpus, so the P panel renders a placeholder. Rows H and O use the Putirka 2-px eq36/eq39 columns as proxies for Brey-Kohler and Putirka cpx-only because separate Brey-Kohler and Putirka cpx-only natural-sample predictions are not in the corpus. Source data: results/nb08_natural_predictions.csv and results/core11_extended_predictions.csv merged on Experiment; row statistics from results/pairing_matrix_22rows.csv.
