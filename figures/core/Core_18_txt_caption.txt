Figure 18. Surrogate decision trees for the four opx winner models. Each of four pages renders a fitted depth-4 CART regression tree trained to predict the winner model's predictions (not the ground-truth target) from the same features, with max_depth = 4 and min_samples_leaf = 10. Surrogate R^2 with 500-bootstrap 95% CI on test-set predictions: opx_liq T = 0.88 [0.85, 0.91] for ElasticNet/raw winner; opx_liq P = 0.81 [0.77, 0.86] for MLP/raw winner; opx_only T = 0.88 [0.84, 0.92] for LightGBM/alr winner; opx_only P = 0.89 [0.83, 0.93] for RF/pwlr winner. All four cells exceed R^2 = 0.81, meaning a human-legible rule list recovers more than 80% of the opaque model's predictions. Each split is labelled with feature name, threshold, and sample count at the node; leaves show the mean prediction value. This is the "flowchart approximation" of the ML: readers can trace any test-set sample through the tree and see which feature thresholds dominate the ML's decision, then cross-check against Core_12 SHAP for quantitative feature attribution. The surrogate is not a replacement model; it is an interpretability layer quantifying how much of the ML can be expressed as a shallow axis-aligned partitioning. Source: results/surrogate_tree_r_squared.csv; full tree visualisations rendered via sklearn.tree.plot_tree.
